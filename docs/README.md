## 📝 文档维护

### 添加新文档

```bash
# 抓取数据放到对应目录
mv new-scrape.md docs/抓取数据/

# 测试报告放到对应目录
mv test-report.md docs/测试报告/
```

### 清理旧文档

```bash
# 清理 30 天前的临时数据
find docs/临时数据 -type f -mtime +30 -delete

# 压缩旧的抓取数据
tar -czf archive.tar.gz docs/抓取数据/old-*.md
```
