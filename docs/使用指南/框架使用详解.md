## 项目概述

### 什么是 Browser Agent？

**Browser Agent** 是一个**全自动的 AI 智能体框架**，它能够：

- ✅ 理解自然语言指令（中文/英文）
- ✅ 自主规划执行步骤
- ✅ 操作浏览器完成复杂任务
- ✅ 从错误中自我修复和学习
- ✅ 模拟人类行为避免检测

### 核心能力

| 能力 | 说明 | 示例 |
|------|------|------|
| **自然语言驱动** | 用日常语言描述目标 | "帮我测试这个网站的登录功能" |
| **AI 智能决策** | LLM 实时规划和决策 | 自动分析页面、选择操作 |
| **自我修复** | 遇到错误自动恢复 | 选择器失效时尝试替代方案 |
| **记忆学习** | 从历史执行中学习 | 记住成功的策略和模式 |
| **人类行为模拟** | 模拟真实用户操作 | 打字节奏、鼠标轨迹 |

### 技术栈

```
┌─────────────────────────────────────────┐
│         应用层                           │
│  CLI 命令 | Node.js 脚本 | REST API      │
├─────────────────────────────────────────┤
│         AI Agent 层                      │
│  Planner | Executor | Reflector | Memory│
├─────────────────────────────────────────┤
│         工具层                           │
│  16 个浏览器自动化工具（MCP 兼容）         │
├─────────────────────────────────────────┤
│         浏览器抽象层                     │
│  HumanBrowser（模拟人类行为）             │
│  ├─ Chromium（完整功能）                 │
│  └─ Lightpanda（轻量快速）               │
└─────────────────────────────────────────┘
```

### 执行流程

```
1. 理解目标
   用户："访问知乎热榜并抓取前 10 条"
   ↓
   
2. 创建计划 (Planner)
   - 步骤 1: 导航到 https://www.zhihu.com/hot
   - 步骤 2: 等待页面加载完成
   - 步骤 3: 抓取热榜列表
   - 步骤 4: 提取标题和热度
   - 步骤 5: 保存结果
   ↓
   
3. 执行循环 (Executor)
   For each 步骤:
     - 获取页面快照
     - 决定具体操作
     - 调用工具执行
     - 记录执行结果
   ↓
   
4. 错误处理 (Reflector)
   If 执行失败:
     - 诊断错误原因
     - 生成恢复策略
     - 尝试替代方案
   ↓
   
5. 记忆存储 (Memory)
   - 保存执行轨迹
   - 记录成功策略
   - 更新学习模式
   ↓
   
6. 生成报告
   - 执行总结
   - 提取的数据
   - 改进建议
```

## 核心组件理解

### 1. Planner（规划器）

**职责**: 理解目标、制定计划、实时决策

**核心方法**:
```javascript
// 理解用户目标
understandGoal(goal)
// 输出：{ type: 'data_extraction', entities: ['知乎', '热榜'], ... }

// 创建执行计划
createPlan(understanding)
// 输出：{ phases: [...], steps: [...], totalSteps: 5 }

// 实时决策下一步
decideNextAction(snapshot, state)
// 输出：{ action: 'browser_click', arguments: {...}, rationale: '...' }
```

**工作流程**:
```
用户输入 → LLM 分析 → 意图识别 → 计划生成 → 步骤分解
                ↓
         当前页面快照 → 状态评估 → 下一步决策
```

### 2. Executor（执行器）

**职责**: 调用工具、执行操作、记录指标

**核心方法**:
```javascript
// 执行单个行动
execute(action)
// 返回：{ success: true, result: {...}, duration: 1234 }

// 带重试的执行
executeWithRetry(action, retryCount, delay)
// 自动重试最多 3 次，每次间隔 1 秒

// 获取执行指标
getMetrics()
// 返回：{ totalActions: 10, successRate: 0.9, avgDuration: 1500 }
```

**执行历史**:
```javascript
executionHistory: [
  {
    timestamp: 1234567890,
    action: 'browser_navigate',
    arguments: { url: 'https://zhihu.com' },
    result: { success: true },
    duration: 2345
  },
  // ...
]
```

### 3. Reflector（反思器）

**职责**: 错误诊断、恢复策略、总结建议

**核心方法**:
```javascript
// 诊断和恢复
diagnoseAndRecover(action, result, state)
// 返回：{ diagnosis: {...}, recoveryStrategy: {...} }

// 生成总结
summarize(state)
// 返回：{ summary: '执行完成', recommendations: [...] }
```

**错误类型处理**:
```javascript
switch (errorType) {
  case 'selector_not_found':
    // 尝试替代选择器
    return useAlternativeSelector();
    
  case 'timeout':
    // 增加等待时间或跳过
    return increaseTimeout();
    
  case 'network_error':
    // 重试或切换网络
    return retryNetwork();
    
  case 'element_not_interactable':
    // 滚动到元素或等待
    return scrollToElement();
}
```

### 4. Memory（记忆系统）

**职责**: 存储执行轨迹、学习优化策略

**核心方法**:
```javascript
// 开始新的 episode
startEpisode(goal)
// 返回：{ id: 'episode-123456' }

// 记录步骤
recordStep(step)
// 保存：action, arguments, result, snapshot, error, duration

// 结束 episode
endEpisode(outcome)
// 计算指标、保存到磁盘、清理过期数据

// 获取成功策略
getSuccessfulStrategies()
// 返回：历史成功执行的策略列表
```

**记忆结构**:
```json
{
  "id": "episode-123456",
  "goal": "抓取知乎热榜",
  "startTime": 1234567890,
  "endTime": 1234568890,
  "steps": [
    {
      "action": "browser_navigate",
      "arguments": { "url": "https://zhihu.com/hot" },
      "result": { "success": true },
      "duration": 2345
    }
  ],
  "outcome": { "success": true, "summary": "成功抓取 10 条热榜" },
  "metrics": { "totalSteps": 5, "successRate": 1.0 }
}
```

### 5. Tool Registry（工具注册表）

**职责**: 管理所有浏览器操作工具

**内置工具** (16 个):

| 工具名称 | 功能 | 参数示例 |
|---------|------|----------|
| `browser_navigate` | 导航到 URL | `{ url: 'https://...' }` |
| `browser_snapshot` | 捕获页面快照 | `{ full: false }` |
| `browser_screenshot` | 截图 | `{ filename: 'test.png' }` |
| `browser_click` | 点击元素 | `{ selector: '#btn' }` |
| `browser_type` | 输入文本 | `{ selector: '#input', text: 'hello' }` |
| `browser_verify` | 验证断言 | `{ assertionType: 'visible', target: '#elem' }` |
| `browser_wait` | 等待 | `{ duration: 1000 }` |
| `browser_scroll` | 滚动 | `{ direction: 'down', amount: 300 }` |
| `browser_hover` | 悬停 | `{ selector: '.menu' }` |
| `browser_evaluate` | 执行 JS | `{ script: 'return document.title' }` |
| `browser_select_option` | 选择下拉项 | `{ selector: '#sel', value: 'opt1' }` |
| `browser_check` | 勾选复选框 | `{ selector: '#chk' }` |
| `browser_upload_file` | 上传文件 | `{ selector: '#file', filePath: '...' }` |
| `browser_press_key` | 按键 | `{ key: 'Enter' }` |
| `browser_new_tab` | 打开标签页 | `{ url: 'https://...' }` |
| `browser_close_tab` | 关闭标签页 | `{}` |

**工具定义格式**:
```javascript
{
  name: 'browser_click',
  description: '点击页面上的交互元素',
  schema: {
    selector: {
      type: 'string',
      description: 'CSS 选择器、XPath 或 ARIA 角色',
      required: true
    },
    strategy: {
      type: 'string',
      enum: ['css', 'xpath', 'aria', 'text'],
      default: 'css'
    }
  },
  handler: async (args, context) => {
    const { selector, strategy = 'css' } = args;
    await context.browser.click(selector, { strategy });
    return { success: true, message: `点击了 ${selector}` };
  }
}
```

## 使用方式详解

### 方式 1: Lightpanda 命令行（最简单）

**适用场景**: 快速抓取静态网页

**基本命令**:
```bash
# 抓取为 Markdown
./lightpanda-x86_64-linux.bin fetch \
  --dump markdown \
  --wait_ms 8000 \
  "https://www.kali.org" \
  > kali.md

# 抓取为 HTML
./lightpanda-x86_64-linux.bin fetch \
  --dump html \
  --wait_ms 8000 \
  "https://cve.mitre.org/" \
  > cve.html

# 截图
./lightpanda-x86_64-linux.bin fetch \
  --dump screenshot \
  --wait_ms 5000 \
  "https://example.com" \
  > screenshot.png
```

**参数说明**:
| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `--dump` | 输出格式 | 无 | `html`, `markdown`, `screenshot` |
| `--wait_ms` | 等待时间 | 5000 | `3000`, `8000`, `10000` |
| `--strip_mode` | 移除标签 | 无 | `js,css`, `full` |
| `--http_timeout` | HTTP 超时 | 30000 | `60000` |
| `--log_level` | 日志级别 | `warn` | `info`, `debug`, `error` |

### 方式 2: Node.js 脚本

**适用场景**: 定制化抓取逻辑

**基本示例**:
```javascript
const { chromium } = require('playwright');

async function fetchWebContent() {
    const browser = await chromium.launch({
        headless: true,
        args: ['--no-sandbox', '--disable-dev-shm-usage']
    });

    const page = await browser.newPage();
    
    // 导航到目标网站
    await page.goto('https://www.kali.org', {
        waitUntil: 'networkidle',
        timeout: 30000
    });
    
    // 提取数据
    const data = await page.evaluate(() => {
        const links = document.querySelectorAll('a[href]');
        return Array.from(links).map(link => ({
            text: link.textContent.trim(),
            href: link.href
        }));
    });
    
    // 保存结果
    const fs = require('fs');
    fs.writeFileSync('result.json', JSON.stringify(data, null, 2));
    
    await browser.close();
}

fetchWebContent();
```

### 方式 3: AI Agent 智能抓取

**适用场景**: 复杂交互任务

**配置环境**:
```bash
# 1. 配置环境变量
cp .env.example .env
vim .env

# 2. 填入 API Key
OPENAI_API_KEY=sk-your-api-key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
BROWSER_BACKEND=chromium
HEADLESS=false
```

**使用示例**:
```javascript
const { AutonomousAgent } = require('./src');

async function main() {
    const agent = new AutonomousAgent({
        llm: {
            provider: 'openai',
            apiKey: process.env.OPENAI_API_KEY,
            model: 'deepseek-chat'
        },
        browser: {
            backend: 'chromium',
            headless: false,
            humanize: true
        },
        agent: {
            maxSteps: 30,
            enableReflection: true
        }
    });

    await agent.launch();

    // 用自然语言描述目标
    const result = await agent.executeGoal(`
    访问知乎热榜页面
    抓取前 10 条热榜的标题和热度
    保存为 JSON 文件
    `);

    console.log('执行结果:', result);

    await agent.close();
}

main();
```

## 常见问题解答

### Q1: Lightpanda 和 Playwright 有什么区别？

**A**: 
| 特性 | Lightpanda | Playwright |
|------|------------|------------|
| **安装** | 无需安装（自带二进制） | 需要安装 Chromium |
| **大小** | ~100MB | ~300MB+ |
| **速度** | 快速 | 较慢 |
| **功能** | 基础抓取 | 完整浏览器功能 |
| **JS 执行** | 有限 | 完整支持 |
| **适用场景** | 静态网页、快速抓取 | 动态网页、复杂交互 |

**推荐**:
- 简单抓取 → Lightpanda
- 复杂交互 → Playwright

---

### Q2: 为什么有时抓取内容为空？

**A**: 可能原因:
1. **等待时间不足** - 增加 `--wait_ms`
2. **动态加载内容** - 使用 Playwright
3. **反爬虫拦截** - 启用 `humanize` 模式
