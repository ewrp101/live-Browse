## Lightpanda 真实抓取

### 基本命令格式

```bash
./lightpanda-x86_64-linux.bin fetch \
  --dump <输出格式> \
  --wait_ms <等待时间> \
  "<目标 URL>" \
  > <输出文件>
```

### 输出格式选项

| 格式 | 参数 | 用途 | 示例 |
|------|------|------|------|
| **HTML** | `html` | 完整网页源码 | `> page.html` |
| **Markdown** | `markdown` | 纯文本内容 | `> page.md` |
| **语义树** | `semantic_tree` | 结构化数据 | `> tree.txt` |
| **截图** | `screenshot` | 页面截图 | `> page.png` |

## 批量抓取脚本

### 创建批量抓取脚本

```bash
cat > batch-scrape.sh << 'EOF'
#!/bin/bash
# 批量网页抓取脚本

# 定义要抓取的网站列表
URLS=(
  "https://www.kali.org"
  "https://cve.mitre.org/"
  "https://nvd.nist.gov/"
  "https://www.boaoforum.org"
  "http://www.gov.cn"
)

# 创建输出目录
OUTPUT_DIR="./scraped-$(date +%Y%m%d-%H%M)"
mkdir -p "$OUTPUT_DIR"

echo "╔════════════════════════════════════════╗"
echo "║   批量网页抓取工具                     ║"
echo "╚════════════════════════════════════════╝"
echo ""
echo "输出目录：$OUTPUT_DIR"
echo "抓取数量：${#URLS[@]} 个网站"
echo ""

# 逐个抓取
for i in "${!URLS[@]}"; do
  url="${URLS[$i]}"
  # 生成文件名（替换特殊字符）
  filename=$(echo "$url" | sed 's/[^a-zA-Z0-9]/_/g' | sed 's/^_//;s/_$//')
  
  echo "[$((i+1))/${#URLS[@]}] 抓取：$url"
  
  # 执行抓取
  ./lightpanda-x86_64-linux.bin fetch \
    --dump markdown \
    --wait_ms 8000 \
    "$url" \
    > "$OUTPUT_DIR/$filename.md" 2>&1
  
  # 检查结果
  if [ $? -eq 0 ]; then
    size=$(ls -lh "$OUTPUT_DIR/$filename.md" | awk '{print $5}')
    echo "  ✅ 成功 - 文件大小：$size"
  else
    echo "  ❌ 失败"
  fi
  
  # 避免过快请求
  sleep 2
done

echo ""
echo "════════════════════════════════════════"
echo "所有抓取完成！"
echo "保存位置：$OUTPUT_DIR"
echo ""
ls -lh "$OUTPUT_DIR"
EOF

chmod +x batch-scrape.sh
```

### 运行批量抓取

```bash
./batch-scrape.sh
```

**预期输出**:
```

  ✅ 成功 - 文件大小：15K
[2/5] 抓取：https://cve.mitre.org/
  ✅ 成功 - 文件大小：12K
...
```

## 数据解析与处理

### 从 HTML 提取标题和 Meta

```bash
cat > extract-meta.sh << 'EOF'
#!/bin/bash
# 提取 HTML 文件的 Meta 信息

HTML_FILE="$1"

if [ ! -f "$HTML_FILE" ]; then
  echo "错误：文件不存在 - $HTML_FILE"
  exit 1
fi

echo "════════════════════════════════════════"
echo "文件：$HTML_FILE"
echo "════════════════════════════════════════"
echo ""

# 提取标题
echo "📄 页面标题:"
grep -o '<title>[^<]*</title>' "$HTML_FILE" | \
  sed 's/<title>//;s/<\/title>//' | head -1
echo ""

# 提取描述
echo "📝 描述:"
grep -o '<meta[^>]*name="description"[^>]*>' "$HTML_FILE" | \
  grep -o 'content="[^"]*"' | \
  sed 's/content="//;s/"$//' | head -1
echo ""

# 提取关键词
echo "🏷️  关键词:"
grep -o '<meta[^>]*name="keywords"[^>]*>' "$HTML_FILE" | \
  grep -o 'content="[^"]*"' | \
  sed 's/content="//;s/"$//' | head -1
echo ""

# 统计
echo "📊 统计信息:"
echo "  链接数量：$(grep -o 'href="[^"]*"' "$HTML_FILE" | wc -l)"
echo "  图片数量：$(grep -o 'src="[^"]*"' "$HTML_FILE" | wc -l)"
echo "  总行数：$(wc -l < "$HTML_FILE")"
EOF

chmod +x extract-meta.sh
```

### 使用 Python 解析 HTML

```bash
cat > parse_html.py << 'EOF'
#!/usr/bin/env python3
"""HTML 解析器 - 提取网页内容"""

from bs4 import BeautifulSoup
import sys
import json

def parse_html(filename):
    with open(filename, 'r', encoding='utf-8') as f:
        html = f.read()
    
    soup = BeautifulSoup(html, 'html.parser')
    
    # 提取标题
    title = soup.find('title')
    
    # 提取所有链接
    links = []
    for link in soup.find_all('a', href=True):
        links.append({
            'text': link.text.strip()[:50],
            'href': link['href']
        })
    
    # 提取所有图片
    images = [img['src'] for img in soup.find_all('img', src=True)]
    
    # 输出结果
    result = {
        'title': title.text.strip() if title else 'N/A',
        'links_count': len(links),
        'images_count': len(images),
        'top_links': links[:10]
    }
    
    print(json.dumps(result, indent=2, ensure_ascii=False))

if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("用法：python3 parse_html.py <html 文件>")
        sys.exit(1)
    parse_html(sys.argv[1])
EOF

chmod +x parse_html.py
```

**使用方法**:
```bash
# 安装依赖
pip3 install beautifulsoup4

# 解析 HTML 文件
python3 parse_html.py kali-org.html
```

## 故障排查

### 问题 1: 抓取超时

**症状**:
```
OperationTimedout
```

**解决方案**:
```bash
# 增加等待时间
--wait_ms 15000

# 增加 HTTP 超时
--http_timeout 60000

# 使用更快的镜像或 CDN
```

### 问题 2: TLS/SSL 证书错误

**症状**:
```
SSL certificate problem
```

**解决方案**:
```bash
# 跳过证书验证（仅测试）
--insecure_disable_tls_host_verification
```

### 问题 3: 内容为空

**症状**:
```
内容长度：0
```

**解决方案**:
```bash
# 增加等待时间（动态内容需要更长时间加载）
--wait_ms 10000

# 尝试不同的输出格式
--dump html  # 而不是 markdown
```

### 问题 4: Playwright 错误

**症状**:
```
browserType.launch: Executable doesn't exist
```

**解决方案**:
```bash
# 方案 1: 使用 Lightpanda（不需要 Playwright）
./lightpanda-x86_64-linux.bin fetch ...

# 方案 2: 安装 Playwright 浏览器
npx playwright install chromium
```

### 问题 5: 动态内容无法抓取

**症状**: JavaScript 渲染的内容抓取不到

**解决方案**:
```bash
# 1. 增加等待时间
--wait_ms 15000

# 2. 使用 CDP 连接（需要启动 serve 模式）
./lightpanda-x86_64-linux.bin serve --host 127.0.0.1 --port 9222

# 3. 使用 Playwright（完整浏览器支持）
node fetch-real-news.js
```

### 3. 错误处理和日志

```bash
#!/bin/bash

URL="$1"
OUTPUT="$2"
LOG="$3"

./lightpanda-x86_64-linux.bin fetch \
  --dump html \
  --wait_ms 8000 \
  "$URL" \
  > "$OUTPUT" 2>&1

if [ $? -ne 0 ]; then
  echo "❌ 抓取失败：$URL" | tee -a "$LOG"
  echo "错误日志：" | tee -a "$LOG"
  cat "$OUTPUT" | tee -a "$LOG"
  exit 1
else
  SIZE=$(ls -lh "$OUTPUT" | awk '{print $5}')
  echo "✅ 抓取成功：$URL (文件大小：$SIZE)" | tee -a "$LOG"
fi
```
